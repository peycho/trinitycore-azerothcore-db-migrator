# Support

Use GitHub Issues for reproducible bugs and narrowly scoped enhancement
requests. Include:

- toolkit commit and both core revisions;
- MySQL server/client versions;
- the failing command and redacted error;
- relevant mapping disposition and validation check;
- a minimal synthetic fixture when possible.

Do not post database dumps, generated reports from real realms, credentials,
email addresses, IP addresses, SRP6 material, or other player/account data.

This project provides no emergency, production, or migration-window support.
Always rehearse, retain verified backups, and keep the original TrinityCore
schemas untouched for rollback.
