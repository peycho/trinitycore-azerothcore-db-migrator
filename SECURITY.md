# Security policy

## Supported versions

Security fixes are made on the current default branch. Historical commits and
forks are not maintained.

## Reporting a vulnerability

Do not open a public issue for vulnerabilities involving credential exposure,
SQL injection, unintended source/world writes, destructive cleanup, privilege
escalation, or unsafe resume behavior.

Use
[GitHub private vulnerability reporting](https://github.com/peycho/trinitycore-to-azerothcore-db/security/advisories/new).
Include the affected commit, configuration conditions, reproduction steps, and
impact. Remove all real credentials and player data.

This is a volunteer project. No response or remediation deadline is guaranteed.
For an active migration, stop the migration and preserve the source databases,
targets, control schema, and sanitized diagnostic output privately.
